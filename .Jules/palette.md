## 2025-05-15 - Improve OTP Accessibility and Form UX
**Learning:** For dynamic mapped inputs like OTP fields, dynamically generating `aria-label`s provides critical positional context for screen reader users (e.g., `Digit 1 of 6`). Additionally, disabling form submit buttons based on missing fields is an anti-pattern as it prevents users from triggering validation and receiving necessary, contextually spoken error feedback.
**Action:** Always map sequential inputs with positional `aria-label` attributes. **Learning:** Adding `role="alert"` and `aria-live="assertive"` to dynamic error message containers ensures screen readers announce validation errors to users when they occur. Also, unlocking submit buttons (by avoiding `disabled={!canSubmit}` anti-patterns) allows users to actually trigger the form validation and read the helpful error messages contextually.
**Action:** Always add ARIA live regions to form error containers and avoid disabling submit buttons based on missing fields.
