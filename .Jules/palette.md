## 2026-09-26 - Explicitly Linking Dynamically Generated IDs in Custom UI Components
**Learning:** When building custom UI components (like a mock-select dropdown where a button acts as the input), screen readers rely on explicit programmatic associations. Even if visually clear, the label and interactive element must be linked. React's `useId()` hook is an excellent tool for safely generating these unique IDs without conflicts, especially when the component is reused multiple times on the same page.
**Action:** Always link `<label>` elements to their corresponding inputs or custom interactive elements (like a `<button>` acting as a select) using dynamically generated IDs (via `useId()`) paired with `htmlFor` on the label and `id` or `aria-labelledby` on the interactive element.
